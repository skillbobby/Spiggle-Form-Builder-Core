Core features

Everything you need to ship intake forms.

The Community Edition ships the visual designer, public renderer, submission inbox, and CSV export — no Pro license required to start publishing.

No-Code Visual Builder

Drag sections and fields onto a canvas inside Filament. Publish when ready — no Blade, no Vue, no build step.

Public Livewire Renderer

Guests get a self-contained Blade + Livewire UI served at /forms/{path}. No Filament CSS leaks to the public side.

Submission Inbox

Filter, review, archive, and bulk-manage responses in the panel — with status filters and an audit log for every export and bulk action.

Validation & Sanitization

Laravel's rule engine validates every submit server-side, and HTML is stripped from plain-text fields automatically.

CSV & JSON Portability

Native CSV export plus JSON export/import (form-builder:export / :import) so definitions travel between environments.

Custom Public Paths

Clean URLs like /forms/contact-us with conflict hashing. Swap the prefix via FORM_BUILDER_ROUTE_PREFIX.

Dynamic Fields Ready

Reuses the same FieldCatalog when Spiggle Dynamic Fields is installed — one field-type system across the suite.

Pro-Ready Architecture

FeatureCatalog and ProUnlock hooks let the licensed add-on layer wizards, tabs, masking, and XLSX export on top of Core.
