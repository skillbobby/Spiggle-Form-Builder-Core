User support for every feature

Matches the Filament visual designer, public Livewire page, and submission inbox in v2.0.3. Items marked PRO require Form Builder Pro.

Builder UI

  • Create wizard: 3-step flow — choose blank or template, pick a gallery template (Core + Pro), land on the visual designer.
  • Visual designer: Drag-drop 3-panel layout (pages + palette / canvas / inspector) on the edit page.
  • Content blocks (Core): heading, paragraph, divider, spacer, banner, image, video, footer, button, section container.
  • Content blocks (Pro): social links, button group, custom HTML.
  • Page chrome: header and footer slots repeat on every public page (Core blocks in header/footer zones).
  • Thank you (Core): Card layout with editable blocks.
  • Thank you (Pro): Review Card (hero, CTA band) and Connect / campaign layout (social cards, website button, auto-redirect).
  • List: name + public path, layout badge, published icon, entries count, Open / Clone (Pro) / Edit / Delete.
  • View form: public URL, schematic preview, analytics charts (Pro), submissions relation.

Labels, overrides, and width

  • Default label position on the form; each field can override.
  • above — label then control (default).
  • inline — CSS row layout on the public field.
  • below — control then label.
  • inside — no outer label; placeholder becomes the label text if placeholder is empty.
  • Label override — runtime display label without changing the stored schema label (used by the public renderer, Filament preview, validation attributes, and submission display).
  • Width — 1–12 of the grid; 12 is full, 6 is half. Always full width on small screens.

Public forms

  • Self-contained CSS in the public layout (12-column grid, mobile stack).
  • Progress bar + “Step N of M” for wizard and pages.
  • Tab pills call goToStep (no step validation when switching tabs).
  • Only published+active forms; match on base_path or slug.
  • Logged-in users are stored on user_id when Auth is present.

File uploads

  • Livewire WithFileUploads. Toggle Allow multiple files on the field (meta.multiple).
  • Stored under form-submissions/{form_id} on FORM_BUILDER_FILE_DISK (default public).
  • Config max_size_kb is 5120; Livewire’s own upload limits also apply (livewire.php / php.ini).
  • Not Spatie Media Library (unlike Dynamic Fields file fields).
  • Exports list original file names separated by semicolons.

Input masking PRO

Per-field masks on text, phone, and number types (not date/datetime pickers). Set meta.input_mask in the inspector:

  • phone — formats as you type, e.g. (555) 123-4567
  • date — MM/DD/YYYY
  • time — HH:MM
  • currency — $0.00

Public forms load a small mask script; stored values are the masked strings visitors entered.

Exports

  • CSV — Core; native fputcsv.
  • XLSX — Pro; SpreadsheetML Excel.
  • PDF — Pro; printable submission export.
  • Headers: id, uuid, form, status, created_at, then each field name (or union of keys if exporting mixed forms).
  • Arrays become comma-separated; file arrays become names joined with ; .
  • Audit log action export with format, filename, count.

Submissions inbox

  • Preview column: first two answered fields as an excerpt.
  • UUID copyable, hidden by default.
  • Analytics charts on the list and form view page (Pro).
  • Empty state: “Publish the form and share its public URL…”

Import from custom fields PRO

Developer API copies definitions into the form schema (see Workflows). After import, edit the form in the builder as usual — it is a one-way snapshot.
