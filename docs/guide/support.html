Troubleshooting, FAQ, and support

Package spiggle/form-builder version 1.0.0. Namespace Spiggle\FormBuilder.

Where to get help

  • GitHub issues: github.com/skillbobby/Spiggle-Form-Builder-Core/issues
  • Repository: github.com/skillbobby/Spiggle-Form-Builder-Core
  • Include package version, Filament/Livewire versions, whether Dynamic Fields is installed, the form’s layout type, and php artisan form-builder:verify output when reporting engine bugs.

Troubleshooting

Forms / Submissions menu missing

  • Register FormBuilderPlugin::make() on the panel.
  • If Shield created permissions, grant manage_forms and/or view_form_submissions (or use super_admin).

Public URL 404s

  • The form must be published and active.
  • Use the exact base_path (list description) or slug. Prefix defaults to /forms/.
  • Run php artisan route:list --name=form-builder to confirm the route loaded.
  • Do not expect /contact-us without prefix unless FORM_BUILDER_ROOT_PATHS=true and the path is not reserved.

Cannot add a second section

Layout is Single page. Switch to wizard, tabs, or pages.

Wizard Next does nothing / validation errors

The current section has required fields. Fill them or mark fields optional. Step 0 only validates the first container.

Drafts disappear

Drafts are session-based, not accounts. New browser / expired session / drafts.enabled = false clears them. File uploads are never drafted.

Export notification but no download in the browser

v1 writes a file on the server and shows the path. Open storage/app/form-builder-exports/ (or the configured disk). Queue connection may be sync; Filament already dispatchSyncs.

Excel file looks like XML

Expected. It is SpreadsheetML so Excel can open it without PhpSpreadsheet. Rename/open in Excel. True OOXML .xlsx is not generated in v1.

PDF shows question marks

The built-in PDF is Helvetica/ASCII. Non-ASCII is replaced with ?. Use CSV/XLSX for full text, or swap a branded engine later without changing the job API.

Notify emails do not arrive

Addresses are stored. There is no mail listener in v1. Listen for FormSubmitted and send mail in the host (respect form-builder.notify if you wire it yourself).

File upload fails on the public form

  • storage:link for the public disk.
  • Livewire temp directory writable; upload_max_filesize / post_max_size.
  • Default cap 5120 KB in package config.

Import custom fields does nothing

Dynamic Fields must be installed. Pass existing custom_fields.id values. If the form has no sections, import creates “Imported fields”.

Livewire missing on public page

The public layout includes Livewire. Do not strip @livewireStyles / @livewireScripts if you publish views.

FAQ

Does this replace Dynamic Fields?

No. Dynamic Fields extends Eloquent records in the admin. Form Builder captures standalone responses. Use both: define profile fields on User, and public forms for guests.

Can I embed a form inside Filament?

FormRenderer::toFilament($form) returns Wizard/Tabs/Section components for admin preview/embed. Public guests should use the Livewire route.

How do I prevent duplicate emails?

Set config('form-builder.validation_hooks') to a callable that adds a custom rule. No built-in remote uniqueness validator ships in v1.

Are submissions searchable by field?

Yes — filter Field contains with the internal name (e.g. email) and a substring. JSON path data->key plus a fallback LIKE on the whole JSON.

What sample forms exist?

form-builder:seed creates contact-us (single), event-registration (wizard), job-application (tabs), customer-feedback (pages).

Can I restyle the public page?

Publish form-builder-views and edit resources/views/vendor/form-builder/layouts/public.blade.php and the field partial.
